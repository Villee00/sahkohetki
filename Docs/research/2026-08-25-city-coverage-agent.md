# Finland-wide city coverage for electricity-transfer-price data

**Checkpoint retrieval date:** 2026-08-25
**Status:** usable checkpoint; the table contains all 108 reconciled city rows, while preserving source and mapping uncertainty.

This report does not claim that one postal code or one DSO is the exact network-wide answer for an entire municipality. The representative DSO is only the result of looking up the selected postal code in the live Sähkönhinta.fi feed; the municipality DSO field is the set of feed operators observed across all 2026 Paavo postal areas assigned to that municipality.

## Result

- Statistics Finland's Municipalities 2026 classification contains **308 municipalities**; the Kuntaliitto directory reconciliation yields **108 city rows**, matching Kuntaliitto's official **108** city-count statement.
- **10** rows have one representative-code DSO match with no recorded caveat.
- **25** rows have one representative-code DSO match but a centre/proxy or municipality-wide multi-operator caveat.
- **73** rows are unresolved for a single-city answer because the representative postal code has multiple DSO matches, is unmapped, or has no selected postal code.
- Representative postal code: **108 selected**, **0 empty**, **1 unmapped in the DSO feed**.
- **72** representative postal codes match multiple DSO names; **88** municipalities have multiple DSO names across their Paavo postal areas; **45** have multiple centre-labelled postal areas; **12** use a proxy centre; **3** use an explicit manual checkpoint proxy.

## City-list derivation and authority limits

1. Statistics Finland's **Municipalities 2026** classification supplied the authoritative 2026 municipality names and municipality codes.
2. Kuntaliitto's current municipal directory supplied the authoritative directory names and per-municipality entry URLs. Kuntaliitto's official explanatory material supplied the target count of 108 municipalities using the designation **kaupunki**.
3. The 108-row set below is the checkpoint reconciliation of those two authoritative 2026 name/code sources against the Kuntaliitto count. The current directory HTML did not expose a consistently machine-readable kaupunki sentence for every individual entry, so the designation provenance is marked Kuntaliitto-count-reconciled rather than overstating that every row has a separately extracted sentence.
4. Maarianhamina is the directory form reconciled to Statistics Finland's bilingual classification form Maarianhamina - Mariehamn.

This is a complete, auditable checkpoint list and not a claim that the per-row designation text has been independently re-extracted from 108 individual municipal pages.

## Methodology

- Postal representative: queried Paavo 2026 statistical postal areas (pno_2026) and grouped them by municipality code. Preferred an area name containing a standalone centre token (keskus, keskusta, centrum, centre, or center) and, within that set, preferred a city-named area. When no such label existed, used a city-named area as a proxy. Multiple labelled centres remain visible in centre_area_candidates and are flagged.
- Explicit manual checkpoint proxies: Vantaa → 01300 Tikkurila, Mänttä-Vilppula → 35800 Mänttä, and Pyhäjärvi → 86800 Pyhäsalmi. These are Paavo 2026 area names chosen because the municipality-name/centre-label heuristic was insufficient; each is flagged.
- DSO lookup: for each selected postal code, matched exact string values against PostalCodes in the DSO feed. All matching operator names are retained; multiple names are not collapsed.
- Municipality plausibility check: matched every Paavo postal area assigned to the municipality against the same feed and retained the observed operator-name set in municipality_dso_names_observed. This is a warning signal, not a legally exact service-area boundary.
- Status meanings: resolved_representative_only means exactly one DSO matched the representative code and no caveat flag was raised; resolved_with_caveat means exactly one matched but a proxy/multiple-area/municipality-wide caveat remains; unresolved means the selected code is unmapped, maps to multiple DSOs, or no representative code was selected.
